# tasks/ — 共同タスクボード運用ルール

久野・Seitaroの2人でプロダクト開発の進捗を共有するためのタスクボード。
全タスクは `board.md` の1本に集約する（職種別ファイルには分けない）。

## feedback/ との役割分担

CEOフィードバック（＝Claude Codeへの指示全般。「CEO」は依頼者本人を指す建て付け）は
**両方に** 記録する。片方だけで終わらせない。

- `feedback/[職種].md` = CEOの好み・傾向を蓄積する**ナレッジDB**（職種別、将来の外部化候補）
- `tasks/board.md` = 同じFBを**実行タスク**として管理する進捗共有ボード（1本集約、チェックで完了管理）

## 書き方

新規タスクを追加するとき：
```
- [ ] [職種タグ] タスク内容 (起票: 名前, YYYY-MM-DD)
```

タスクを完了したとき（`[ ]` を `[x]` に変え、完了者と完了日を追記する）：
```
- [x] [職種タグ] タスク内容 (起票: 名前, YYYY-MM-DD / 完了: 名前, YYYY-MM-DD)
```

完了したタスクは `board.md` 内の「未完了」セクションから「完了」セクションへ移動する。

## 職種タグ一覧

`frontend` / `mobile` / `backend` / `qa` / `network-security` / `infra` /
`corporate-planning` / `ui-ux` / `brand` / `planning` / `marketing` / `sales` / `finance` / `hr`

1つのタスクが複数職種にまたがる場合はタグを複数つけてよい（例: `[frontend][backend]`）。

## 運用方針

- CEOフィードバック（指示全般）はその場でタスク化し、即座に `board.md` に追記する。
- どちらが追加してもよい。追加者は必ず「起票」に自分の名前を残す。
- 完了させたら必ずチェックを入れて完了者・完了日を記録する。これにより、お互いに何がどこまで進んだか一目で分かる状態を保つ。
