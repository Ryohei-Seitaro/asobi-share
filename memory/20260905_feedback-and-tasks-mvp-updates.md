# CEOフィードバック9項目の実装と共同タスクボードの新設

## 内容
CEOフィードバック9項目（実写真化・Googleマップ/食べログ連携・保存報酬のコイン化・
並べ替え機能・チャット気分提案・アクティビティジャンル拡充・検索ウィザードの独立・
有料ライン可変位置）を `mockup/itinerary-mock.html` に実装した。

あわせて、`feedback/[職種].md`（CEO FBのナレッジ蓄積）とは別に、久野・Seitaroが
進捗を共有できる `tasks/board.md` を新設。CEOのFBは実質タスクなので、両方に
同時記録する運用ルールを `CLAUDE.md` に追記した。

## 決定事項
- ホーム画面（見つける）はまずカード一覧を表示し、条件を1問ずつ絞り込む
  ウィザードは「検索」タブとして独立させた（当初はホーム内の1画面フローだったが変更）。
- 保存数の報酬は現金ではなくアプリ内コインとし、有料コンテンツは現金/コインの
  どちらでも購入できる設計にした（前払式支払手段の該当性は要コーポレート確認）。
- 投稿者は有料ラインをタイムライン上の好きな位置に挿入できるようにした
  （従来の「先頭1件無料固定」から変更）。
- モックの写真はWikimedia Commonsのフリー画像（CC系ライセンス）をリサイズして
  data URIで埋め込み。実在の観光地と完全一致しないカットもある（モック目的優先）。

## 影響範囲
- asobi-share: `mockup/itinerary-mock.html`、`CLAUDE.md`、`feedback/*.md`、`tasks/`新設
- 次のアクション: モック確定後にWebアプリ（Next.js等）としての本実装に着手する
