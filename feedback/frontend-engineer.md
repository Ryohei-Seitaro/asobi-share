# feedback/frontend-engineer.md — フロントエンジニアへのCEOフィードバック蓄積

CEOからのフィードバックのうち、フロントエンジニアの観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

## 2026-09-05
- モック画像をSVGプレースホルダーから実写真イメージに置き換えてほしい（イメージが湧かないため）。
- 旅程エディタで場所（ロッカー等）をタップするとGoogleマップの場所情報へ遷移できるようにしたい。
- 昼食などの飲食スポットもGoogleマップ／食べログへの外部リンクにしたい。
- 旅程一覧を「ランキング順」「いいね順」で並べ替えられるようにしたい。
- チャット起動ボタンを設置し、気分を質問（選択式or自由記入）→旅程提案する機能が欲しい。
- 発見画面の1問目を「明日なにする？」の1問だけにし、以降クイック選択で条件を段階的に絞り込むウィザード形式に再設計（時期→誰と→人数→出発地→移動時間→予算→天気自動取得→提案）。
- 投稿者（旅程作成者）が有料ラインをタイムライン上の好きな位置に挿入できるUIにしたい（現状は先頭固定だった）。

## 2026-09-06
- マイページに「保存した旅程」を確認できるセクションを追加してほしい。
- 見つける画面のソートタブ（保存が多い順・ランキング・いいね）の横に「わたしの旅程」「保存済み」タブを追加し、そちらからも自分の投稿・保存を見られるようにしたい。
- 見つける画面で、既に保存済みの旅程にはひと目でわかるマークをつけてほしい。
- マイページの「わたしの旅程」「保存した旅程」一覧は見つける画面のタブに統合したので、マイページからは削除してほしい（統計情報は残す）。
- 見つける画面のフィルタがジャンルしかないので、人数・日数・国内海外なども含めてあらゆる条件で絞り込めるようにしてほしい。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**


### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 修正前の問題：[何が合わなかったか]
- CEOの指示：[具体的な修正指示]
- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```

## ログ

## 2026-09-06
- タスク概要：「つくる」画面のドラッグ予定作成・1分刻み化、マイページの受け取り/チャージ導線、検索ウィザードの自由記入欄、メモからの旅程自動生成、旅程カードの写真スライド化など複数機能の実装依頼。
- 修正前の問題：マイページの「受け取る」「コインをチャージする」ボタンが未接続（クリックしても何も起きない）だった。検索ウィザードは選択肢しかなく、当てはまらない回答を入力できなかった。他アプリで書いた旅程メモをこの媒体に投稿する導線がなかった。
- CEOの指示：ボタンは実際の画面（振込先登録・チャージ）につなぐ。ウィザードの各設問に自由記入欄を追加する。「つくる」画面に付箋（メモ取り込み）ボタンを設け、テキストと写真を入れると旅程形式に自動整形されて投稿できるようにする。
- 傾向メモ：機能追加の際、見た目だけでなく「実際に最後まで機能する導線」であることを重視する（ボタンを置くだけで終わらせない）。また、他アプリ・他サービスとの相互運用性（データの持ち込み・持ち出し）を重視する傾向がある。
