# feedback/planning.md — 企画へのCEOフィードバック蓄積

CEOからのフィードバックのうち、企画の観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

## 2026-09-05
- 保存数で受け取れる報酬を現金ではなく「アプリ内専用コイン」に変更。有料旅程・有料コンテンツは「お金で買う」か「コインで買う」を選べる設計にしたい（要ファイナンス・コーポレート確認）。
- チャットで「今日の気分」を質問（選択式or自由記入）し、それに応じた旅程提案を行う機能のアイデア。
- アクティビティ別ジャンル分けを拡充（山登り・ゴルフ・釣り・キャンプ・海・川・湖・BBQ・スノボ・スキー・ピックルボール等）。
- 発見フローを1問ずつのウィザード形式に再設計する方向性（時期/誰と/人数/出発地/移動時間/予算→天気自動取得→提案）。
- 投稿者が旅程内の好きな位置に有料ラインを挿入できるようにしたい（現状は「最初の1件だけ無料」の固定位置だった）。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**

## 記録フォーマット

### ポジティブフィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 良かった点：[CEOが評価した具体的な内容]
- 再利用ポイント：[次回同様のタスクで使える要素]
```

### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 修正前の問題：[何が合わなかったか]
- CEOの指示：[具体的な修正指示]
- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```
