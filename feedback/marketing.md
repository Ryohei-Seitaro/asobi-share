# feedback/marketing.md — マーケティングへのCEOフィードバック蓄積

CEOからのフィードバックのうち、マーケティングの観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**

---

## 記録フォーマット

### ポジティブフィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 良かった点：[CEOが評価した具体的な内容]
- 再利用ポイント：[次回同様のタスクで使える要素]
```

### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 修正前の問題：[何が合わなかったか]
- CEOの指示：[具体的な修正指示]
- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```
