# feedback/qa-engineer.md — 品質管理エンジニアへのCEOフィードバック蓄積

CEOからのフィードバックのうち、品質管理エンジニアの観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**

---

## 記録フォーマット

### ポジティブフィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 良かった点：[CEOが評価した具体的な内容]
- 再利用ポイント：[次回同様のタスクで使える要素]
```

### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 修正前の問題：[何が合わなかったか]
- CEOの指示：[具体的な修正指示]
- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```

---

## ログ

## 2026-09-06
- タスク概要：「見つける」から具体的な旅程を開くとNeon DBエラーが出る、との不具合報告を受けて調査・修正。
- 修正前の問題：pullしたスキーマ変更（`trip_events.map_url` / `tabelog_url`）が各自の個人用Neonに反映されておらず、旅程一覧は表示できるが**詳細ページだけ**500になっていた。一覧クエリは新カラムを触らないため、トップだけ見ると正常に見えてしまう。
- CEOの指示：エラーを直す（原因はスキーマ反映漏れ）。
- 傾向メモ：スキーマ変更を含むPRをpull／マージした後は、一覧だけでなく**新カラムを参照する画面（詳細・編集）まで開いて**確認する。`.env.local` はgitignoreで共有されないので「他の人の環境では別途 `db:push` が要る」を動作確認チェックの前提に入れる。
