# feedback/ui-ux-designer.md — UI/UXデザイナーへのCEOフィードバック蓄積

CEOからのフィードバックのうち、UI/UXデザイナーの観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

## 2026-09-05
- カード・予定に貼る画像をSVGプレースホルダーではなく実写真にしてイメージが湧くようにしたい。
- 旅程一覧の並べ替え軸として「ランキング順」「いいね順」を追加したい。
- アクティビティ別ジャンルタグを拡充（山登り・ゴルフ・釣り・キャンプ・海・川・湖・BBQ・スノボ・スキー・ピックルボール等）。
- 発見画面の初期フローを1問1答のウィザード形式に再設計（明日なにする？→時期クイック選択→誰と→人数→出発地→移動時間→予算→天気自動提案→おすすめを見る）。

## 2026-09-06
- マイページと見つける画面の両方に「自分の投稿」「保存済み」を置くのは冗長。見つける画面のタブに
  一本化し、マイページは統計情報（保存数・いいね数・受け取り金額等）のみに整理する方針になった。
- 見つける画面のフィルタは、ジャンル単体の横並びchipsではなく「フィルタ」としてまとめ、人数・日数・
  国内海外・予算まで一箇所で選べるようにしたい。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**


### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]

- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```

## ログ

## 2026-09-06
- タスク概要：「つくる」画面の予定作成UI、検索ウィザード、旅程カードの写真表示など複数箇所の改善依頼。
- 修正前の問題：予定作成がフォーム入力のみでGoogleカレンダーのような直感的な操作ができない、時間刻みが15分と粗い、ジャンル選択が予定単位では不要、旅程カードの写真が3枚しか見えず他の写真が見られない。
- CEOの指示：Googleカレンダーのようにタイムラインをドラッグして予定を作れるようにする、時間は1分刻みにする、予定作成時のジャンル入力は撤廃する、旅程カードの写真はスライドで全部見られるようにする。
- 傾向メモ：このCEOは「有名サービス（Googleカレンダー）の操作感・データ互換性」を強く重視する。独自UIより、ユーザーが既に慣れているメジャーサービスの挙動に寄せることを優先する。また入力の手間を減らす方向（不要な必須項目の撤廃、自由記入欄の追加）を一貫して好む。

## 2026-09-06
- タスク概要：「つくる」画面の有料ラインの操作方法の見直し。
- 修正前の問題：有料ラインの位置は、各境界にある「ここから先を有料にする」ボタンをクリックして切り替える方式だった。
- CEOの指示：有料ラインをドラッグで動かせるようにしたい。
- 傾向メモ：クリックによる離散的な切り替えよりも、直接つまんで動かす直感的な操作を一貫して好む（予定作成のドラッグ操作の要望と同じ傾向）。
