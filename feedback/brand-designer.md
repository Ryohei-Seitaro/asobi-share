# feedback/brand-designer.md — ブランドデザイナーへのCEOフィードバック蓄積

CEOからのフィードバックのうち、ブランドデザイナーの観点に関するものをここに記録する。
一定量たまった段階で、職種別エージェントの知見データとして外部化する候補になる。

**記録タイミング：CEOのフィードバックが発生した瞬間に即時記録。**

---

## 記録フォーマット

### ポジティブフィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 良かった点：[CEOが評価した具体的な内容]
- 再利用ポイント：[次回同様のタスクで使える要素]
```

### 修正フィードバック
```
## [YYYY-MM-DD]
- タスク概要：[何を依頼したか]
- 修正前の問題：[何が合わなかったか]
- CEOの指示：[具体的な修正指示]
- 傾向メモ：[このCEOはこういう好みがある、という一般化]
```

---

## ログ

## 2026-09-06
- タスク概要：ダミーデータの人物名、SNSシェアアイコンの見直し依頼。
- 修正前の問題：ダミーユーザー名が「あいり」のまま各所（シードデータ・モック）に残っていた。SNSシェア導線のX/LINE/Instagramアイコンが簡易な線画プレースホルダーで、実際のブランドロゴになっていなかった。
- CEOの指示：ダミー人物名は「あそびくん」に統一する。X・Instagram・LINEのアイコンは公式ロゴ相当のものに差し替える。
- 傾向メモ：プレースホルダー感の残る細部（ダミー名・アイコン）にも敏感で、本番相当の見た目に近づけることを重視する。ブランドロゴは各社のガイドラインに沿った色・形を使うべきという意識が強い。
